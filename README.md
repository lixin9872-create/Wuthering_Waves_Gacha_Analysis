# 鸣潮抽卡模拟器

基于《抽卡概率.docx》中的规则实现的鸣潮（Wuthering Waves）抽卡模拟程序。

| 文件 | 说明 |
|---|---|
| `鸣潮抽卡模拟器.exe` | **打包好的独立程序（双击即可启动网页前端，无需安装 Python）** |
| `app.py` | Web 前端后端（仅用 Python 标准库，无需额外安装） |
| `index.html` | 可交互 Web 前端页面 |
| `static/chart.umd.min.js` | Chart.js 图表库（已本地化，离线可用） |
| `gacha_sim.py` | 核心模拟逻辑库（蒙特卡洛 + 动态规划校验，仅依赖 numpy） |
| `gacha_cli.py` | 命令行 / 交互式入口（含概率分布图 PNG 输出） |

## 直接使用（exe）

双击项目目录下的 **`鸣潮抽卡模拟器.exe`** 即可：它会启动本地服务并自动打开浏览器
（http://127.0.0.1:8000）。首次启动解压需几秒。关闭弹出的黑色控制台窗口即停止服务。
exe 已内置网页与图表库，可单独拷贝到任何电脑运行（可能需要等待 Windows SmartScreen/杀软放行）。

## Web 前端（源码方式）

在项目目录下运行：

```bash
python app.py
```

会自动打开浏览器访问 http://127.0.0.1:8000 。页面上可直接选择：

- **功能**：抽出概率（N 抽内出 K 个 UP）/ 抽数期望（K 个 UP）/ 武器+角色 合计版
- **抽卡池**：角色池 / 武器池（合计版下两池同时参与）
- **抽数 N / UP 数量 K**、**是否大保底**、**已垫抽数**（0~78 滑块）、**模拟次数**
- 合计版额外提供：合计模式（概率/期望）、角色 UP 数量、武器 UP 数量、武器池垫抽数

点击「开始模拟」即可实时得到蒙特卡洛结果 + 解析精确值 + 概率分布图（直方图 / CDF 曲线，悬停可查看数值）。停止服务按 `Ctrl+C`。



## 概率规则（实现口径）

角色池与武器池的“出金（五星）”概率曲线相同：

| 抽数区间 | 出金概率 |
|---|---|
| 第 1 ~ 65 抽 | 固定 0.8% |
| 第 66 ~ 70 抽 | 每抽递增 4% |
| 第 71 ~ 75 抽 | 每抽递增 8% |
| 第 76 ~ 78 抽 | 每抽递增 10% |
| 第 79 抽 | 100%（硬保底） |

- **角色池**：出金时抽到“当期 UP 角色”的概率为 50%（小保底）；若没抽到，则下一次出金必为当期 UP（大保底）。
- **武器池**：出金时抽到“当期 UP 武器”的概率为 100%（无 50/50）。

> 说明：原文“第 71~75 抽递增 8%”与“第 75~78 抽递增 10%”在第 75 抽处重叠。
> 本程序按常见口径把 +10% 区间视为第 76~78 抽，使第 79 抽恰好达到 100%
> （即 66~70 共 5 抽 +4%、71~75 共 5 抽 +8%、76~78 共 3 抽 +10%）。
> 如需调整，直接修改 `gacha_sim.py` 中的 `five_star_rate()` 函数即可。

## 三个功能

1. **功能 1**：计算“在 N 抽内抽齐 K 个当期 UP”的概率。
   输入：抽数 N、需要的 UP 数量 K（1 个起）、下一个是否为大保底、已垫多少抽（pity）。
2. **功能 2**：计算“抽出 K 个当期 UP”还需要的抽数期望。
   输入：需要的 UP 数量 K、下一个是否为大保底、已垫多少抽（pity）。
3. **功能 3（武器+角色 合计版）**：角色池与武器池一起抽，两种子模式：
   - **抽出概率**：在总预算 N 抽内抽齐“C 个角色 + W 个武器”的概率；
   - **抽数期望**：抽齐“C 个角色 + W 个武器”所需的总抽数期望。
   输入：角色 UP 数量 C、武器 UP 数量 W、角色池是否大保底、角色池/武器池各自已垫抽数。

每个功能都做 **10 万次蒙特卡洛模拟**并输出概率分布图，同时用动态规划给出**解析精确值**做交叉校验。
抽数期望模式（功能 2 与功能 3 的“抽数期望”子模式）除了抽数分布直方图外，还附有**累计概率 CDF 曲线**（模拟曲线与解析精确曲线叠加显示，可看出任意抽数预算下的完成概率）。
合计版中两池相互独立，总抽数 = 角色抽数 + 武器抽数（期望直接相加，概率用卷积精确计算）。

## 参数含义

- `pity`（垫抽数）：自上一个五星以来已经抽了多少抽，范围 0~78。`pity=78` 表示下一抽必出金。
- `guaranteed`（大保底）：下一个五星是否必为当期 UP。
  角色池：上一个小保底歪了 → 传 `--guaranteed`；武器池该参数无意义（恒为当期 UP）。

## 用法

### 交互式（直接运行，按提示输入）

```bash
python gacha_cli.py
```

### 命令行

功能 1（80 抽内抽到当期 UP 角色的概率，垫 0 抽、无大保底）：

```bash
python gacha_cli.py --feature 1 --banner character --pulls 80 --pity 0
```

功能 2（抽出 2 个当期 UP 武器还需要的抽数期望，垫 20 抽、无大保底）：

```bash
python gacha_cli.py --feature 2 --banner weapon --ups 2 --pity 20
```

带大保底（角色池，垫 30 抽，下一个必为当期 UP）：

```bash
python gacha_cli.py --feature 2 --banner character --ups 1 --pity 30 --guaranteed
```

### 命令行参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--feature` | `1`=概率，`2`=抽数期望；省略则进入交互模式 | 交互 |
| `--banner` | `character`=角色池，`weapon`=武器池 | `character` |
| `--pulls` | 功能 1 的抽数 N | — |
| `--ups` | 功能 2 需要的当期 UP 数量 K | — |
| `--guaranteed` | 下一个五星是否为大保底（加此参数=是） | 否 |
| `--pity` | 已垫抽数（0~78） | 0 |
| `--trials` | 蒙特卡洛模拟次数 | 100000 |
| `--seed` | 随机种子（可复现结果） | 随机 |
| `--out` | 图片输出目录 | 脚本所在目录 |

## 输出

- 控制台打印：蒙特卡洛结果 + 解析精确值 + 标准误。
- 图片文件：
  - `feature1_<池>_n<N>_g<0|1>_p<pity>.png`：功能 1 的概率分布图（首次出货的概率质量分布 + 累计概率 CDF）。
  - `feature2_<池>_k<K>_g<0|1>_p<pity>.png`：功能 2 的所需抽数分布直方图（标注期望/中位数/标准差）。

## 依赖

- 网页前端 / exe：运行时只需 `numpy`（exe 已自带，无需安装任何东西）。
- 命令行 `gacha_cli.py`：额外需要 `matplotlib`（用于生成 PNG 分布图）。

```bash
pip install numpy matplotlib
```

Python 3.8+ 均可运行。

## 重新打包 exe（可选）

改完代码后，用 PyInstaller 重新打包：

```bash
pip install pyinstaller
python -m PyInstaller --onefile --clean --name 鸣潮抽卡模拟器 app.py --add-data "index.html;." --add-data "static;static"
# 产物在 dist\鸣潮抽卡模拟器.exe
```
